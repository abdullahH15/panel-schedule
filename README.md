# جدول الأحمال التفاعلي — Panel Schedule

أداة ويب في ملف واحد لإعداد جداول أحمال اللوحات الكهربائية وفق **SBC 401 / IEC 60364-5-52**، مع اختيار القواطع والكابلات القياسية تلقائياً. صُممت لمهندسي التصميم والإشراف في السعودية (400/230V، 60Hz، ظروف SEC).

## التشغيل

افتح `index.html` في أي متصفح. لا تحتاج تثبيتاً ولا خادماً.

- يعمل دون إنترنت. الإنترنت مطلوب فقط لتحميل الخطوط ومكتبة تصدير Excel.
- اللوحة الحالية تُحفظ تلقائياً في المتصفح. للاحتفاظ بها خارجه صدّر نسخة JSON.

## ما تفعله الأداة

- **مكتبة أحمال مصنفة** (نحو 100 حمل في 13 فئة): إنارة، مقابس، أجهزة، مطابخ، سخانات، تكييف بالطن وEER، مضخات ومحركات، مصاعد، UPS وتقنية المعلومات، شواحن سيارات، ملاعب، بنية تحتية، سلامة وحريق.
- **9 أنواع مشاريع** تحدد معاملات الطلب والأحمال المقترحة: مكاتب، سكني، تجاري، مساجد، مدارس، مستشفيات، فنادق، ملاعب، بنية تحتية.
- **اختيار القاطع**: أصغر قيمة قياسية ≥ Ib (× 1.25 للمحركات والتكييف والشواحن، واختيارياً للأحمال المستمرة)، مع المنحنى وRCD حسب الفئة.
- **اختيار الكابل**: أصغر مقطع يحقق Ib ≤ In ≤ Iz بعد تصحيح الحرارة والتجميع والتربة، ثم يكبَّر إذا تجاوز هبوط الجهد الكلي الحد.
- **طرق التمديد**: B1، B2، C، E، D1 (مواسير مدفونة)، D2 (دفن مباشر)، بعزل PVC أو XLPE.
- **حسابات اللوحة**: الحمل الموصول والمطلوب لكل طور، عدم الاتزان، تيار المحايد، القاطع الرئيسي، Busbar، كابل التغذية (مع كابلات متوازية عند الحاجة)، ترقيم الدوائر على مخارج TPN.
- **قواعد خاصة**: تباين المصاعد (1 / 0.75 / 0.6)، استبعاد المعدات الاحتياطية وأحمال وضع الحريق من الطلب العادي.
- **موازنة الأطوار تلقائياً** مع توزيع الدوائر المتشابهة على الأطوار الثلاثة.
- **ملاحظات تحقق**: قاطع أكبر من قدرة كابله، هبوط جهد زائد، دوائر مقابس بدون RCD، مخارج احتياطية ناقصة، سعة قطع أقل من تيار القصر.
- **التصدير**: Excel (.xlsx)، CSV، ورقة طباعة HTML، JSON، والنسخ للصق في Excel.

## أساس الحساب

| البند | المرجع |
| --- | --- |
| قدرة الكابلات النحاسية | IEC 60364-5-52:2009، الجداول B.52.2 وB.52.4 وB.52.5 وB.52.12 |
| تصحيح الحرارة والتربة والتجميع | الجداول B.52.14 حتى B.52.19 |
| هبوط الجهد | الملحق G: ρ = 1.25 × ρ20، مفاعلة 0.08 mΩ/m |
| حدود هبوط الجهد الافتراضية | 3% إنارة و5% غيرها من شبكة الجهد المنخفض، 6% و8% من محول خاص |
| الموصل الأرضي | IEC 60364-5-54 |
| ظروف التشغيل الافتراضية | SEC: 40°C داخل المباني غير المكيفة، 40°C للتربة، 2.0 K·m/W |

الجداول المذكورة طوبقت رقماً رقماً مع نص المعيار (انظر `tests/iec-tables.test.js`). **لم تُطابَق بعد**: الجدول B.52.3 (XLPE بموصلين محمّلين) والجدول B.52.10 (PVC على حامل كابلات). في الطريقة D2 تُستخدم قيم الثلاثة موصلات لكابلات XLPE الأحادية، وهي أكثر تحفظاً.

معاملات الطلب قيم استرشادية لكل نوع مشروع يعتمدها الاستشاري؛ SBC 401 يسمح بالتباين دون جدول ثابت.

## ما يجب أن يراجعه المهندس

- قيم MCA وMOCP من لوحة وحدات التكييف المعتمدة.
- تيار البدء للمحركات الكبيرة.
- سعة القطع والتمييز من دراسة تيار القصر.
- كتالوج الكابل الفعلي إذا اختلف عن جداول IEC.
- الأداة لا تحسب كابلات الألمنيوم.

## هيكل المشروع

```
index.html              الصفحة الجاهزة (ناتج البناء)
src/index.src.html      القالب والتنسيق
src/engine.js           محرك الحساب والجداول الهندسية ومكتبة الأحمال
src/app.js              الواجهة والتصدير والحفظ
tests/                  اختبار المثال المحلول ومطابقة جداول IEC
build.py                يدمج src في index.html
```

## التطوير

```bash
python3 build.py   # يبني index.html من src
npm test           # يشغّل الاختبارات (Node.js)
```

عدّل الملفات داخل `src/` ثم أعد البناء. لا تعدّل `index.html` مباشرة.
